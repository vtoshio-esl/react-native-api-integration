# Lamborghini Garage
> App que apresenta uma coleção de veículos da Lamborghini

- Integração com API externa utilizando axios
- Customização da splash screen com `@expo-splash-screen` 
- Arquitetura do projeto organizada (Aplicação de conceitos de Clean Architecture para divisão de responsabilidades)
